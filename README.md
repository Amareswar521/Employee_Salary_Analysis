# Employee_Salary_Analysis

## Project Overview
This beginner-level SQL project analyzes employee salaries
and department information.

## Database Tables
- Departments
- Employees_data
- Salaries

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- JOIN
- COUNT()
- AVG()
- MAX()
- MIN()
- LIMIT
- OFFSET
  
## Objective
To analyze employee salary information and generate
basic business insights.
