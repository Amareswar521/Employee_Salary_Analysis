##Employee_salary_analysis
The **Employee Salary Analysis** project is a beginner-friendly SQL project developed to analyze employee salary information and department-wise employee details.

The main objective of this project is to understand employee salary distributions, compare salaries across departments, identify the highest and lowest salaries, and generate useful insights using SQL queries.

This project uses three relational database tables: `Employees_data`, `Departments`, and `Salaries`. SQL queries are used to retrieve, filter, sort, and analyze employee information.

### Project Objectives
- Analyze employee salary information.
- Find the highest and lowest employee salaries.
- Calculate average salaries.
- Count employees in each department.
- Retrieve employee details using JOIN operations.
- Filter and sort employee records.
- Practice pagination using LIMIT and OFFSET.

### Tools Used
- MySQL
- MySQL Workbench
- GitHub

### Key Learnings
Through this project, I gained practical experience in SQL fundamentals, relational databases, and basic data analysis.
