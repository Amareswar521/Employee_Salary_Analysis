## Employee_Salary_Analysis

This is my beginner-level SQL project. I created this project to practice SQL and learn how to work with employee and salary data.

In this project, I used three tables: `Employees_data`, `Departments`, and `Salaries`. I wrote SQL queries to get employee details, check salaries, and understand department-wise information.

### Project Objectives

- Find employee salary details.
- Find the highest and lowest salaries.
- Calculate the average salary.
- Count employees in each department.
- Get employee and department details using JOIN.
- Filter and sort employee records.
- Use LIMIT and OFFSET to display records.
